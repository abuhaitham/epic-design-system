Line icon (Lucide geometry, 1.75 stroke) used inside buttons, lists and accordions; arrows mirror automatically in RTL.

```jsx
<Icon name="arrow-right" size={18} />
<Icon name="check" style={{color:'var(--accent)'}} />
```

Names: arrow-right, arrow-left, arrow-up-right, chevron-down, chevron-right, plus, minus, check, x, menu, globe, message-circle, mail, calendar, linkedin, map-pin, badge-check. Inherits `currentColor`.
